# Flutter Animation Skill

## Rôle
Créer des animations fluides (60/120 FPS) pour valoriser l'expérience produit sans surcharger le processeur.

## Outils & Widgets
1. **Animations Implicites**: `AnimatedContainer`, `AnimatedOpacity`, `AnimatedCrossFade` pour les transitions simples sans contrôleur manuel.
2. **Hero Animations**: Transitions fluides d'images entre le catalogue et la fiche produit (`Hero(tag: product.id)`).
3. **Animations Explicites**: `AnimationController` avec `CurvedAnimation` pour des courbes naturelles (`Curves.easeOutCubic`).
