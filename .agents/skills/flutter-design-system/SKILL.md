# Flutter Design System Skill

## Rôle
Uniformiser tous les composants graphiques de l'application au sein d'un Design System cohérent et évolutif.

## Structure
1. **Design Tokens**: `AppColors`, `AppSpacing`, `AppTypography`, `AppRadius`, `AppShadows`.
2. **Composants Réutilisables**: `AppButton`, `AppTextField`, `AppCard`, `AppBadge`, `AppBottomSheet`.
3. **Harmonie de Marque**: Palette AquawaSouk (Deep Ocean `#0284c7`, Cyan `#0ea5e9`, Dark Slate `#020617`, Amber `#f59e0b`).
