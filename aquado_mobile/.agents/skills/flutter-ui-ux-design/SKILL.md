# Flutter UI/UX Design Skill

## Rôle
Moderniser l’interface et l’expérience utilisateur mobile selon les standards Material 3 et Cupertino modernes.

## Directives UI/UX
1. **Hiérarchie Visuelle**: Espacements cohérents (système 8pt: 8, 16, 24, 32dp), typographie moderne (Google Fonts / Poppins / Inter).
2. **Micro-interactions**: Effets tactiles (`InkWell`, `BouncingScrollPhysics`), retours haptiques subtils (`HapticFeedback.lightImpact()`).
3. **États d'écran**: Toujours concevoir les 4 états essentiels : Chargement (Shimmer/Skeleton), Données, État vide (Empty State illustré), et Erreur avec bouton Réessayer (Retry).
4. **Ergonomie mobile**: Zones tactiles minimales de 48x48dp, navigation facilitée au pouce (BottomNavigationBar, Floating Action Buttons).
