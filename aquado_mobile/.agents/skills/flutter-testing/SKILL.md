# Flutter Testing Skill

## Rôle
Concevoir et exécuter des suites de tests fiables (Unit, Widget, Integration Tests).

## Stratégie de Test
1. **Tests Unitaires**: Tester la logique métier, les calculs de prix, la validation de formulaires et les mappers JSON (`flutter test`).
2. **Tests de Widgets**: Tester le comportement interactif (`testWidgets`, `tester.pumpAndSettle()`, simulation de clics et saisie).
3. **Mocks & Fakes**: Utiliser `mocktail` ou `mockito` pour simuler les API et repositories sans dépendances réseau.
